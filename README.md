# **Brothers in Arms Memorial - Final Integrated Project**  

This repository contains all files and assets for the **Brothers in Arms Memorial** project, developed by *The Visionaries*.  

The project aims to create a professional marketing and advertising campaign, alongside a mobile-first, responsive website, to raise awareness and drive donations for a memorial commemorating the collaboration between Indian and Canadian soldiers during World War I.

## **Introduction**  
The **Brothers in Arms Memorial** highlights the shared sacrifices and collaboration between Indian and Canadian soldiers during World War I. This project includes a mobile-first website, a marketing campaign, and promotional materials designed to honor their legacy, inspire future generations, and drive donations for the memorial's construction.  


## **Key Components**  

### **1. Branding**  
- Custom logos, color schemes, typography, and visual identity assets.  

### **2. Website**  
- Mobile-first, responsive design built with **Vue.js** and modern web development practices.  
- Backend API powered by **Lumen PHP framework** and a custom-built CMS.  
- Dynamic form handling with AJAX for seamless user experiences.  

### **3. Social Media Campaign**  
- Prototypes and mockups for **Facebook** and **Instagram** campaigns.  
- Strategies to raise awareness and engage audiences.  

### **4. Marketing Materials**  
- Professionally designed brochures, posters, videos, and infographics.
