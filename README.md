# **Brothers in Arms Memorial - Final Integrated Project**

This repository contains all the files and assets for the **Brothers in Arms Memorial** project.  
The objective of this project is to create a professional marketing and advertising campaign, alongside a mobile-first responsive website, to raise awareness and drive donations for the memorial commemorating the collaboration between Indian and Canadian soldiers during World War I.

---

## **Key Components**

### **Branding**  
- Logos, color schemes, and other visual elements.

### **Website**  
- Mobile-first, responsive design using Vue.js and modern web standards.  
- Backend API using Lumen PHP framework with a custom CMS.  
- Form handling with AJAX for dynamic content updates.

### **Social Media Campaign**  
- Mockups and prototypes for Facebook and Instagram campaigns.

### **Marketing Materials**  
- Brochures, posters, videos, and infographics to promote the memorial.
